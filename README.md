## ✨ Features

- **Responsive Design:** Fully adaptive layout for mobile, tablet, and desktop.
- **Animated Hero Section:** Smooth floating profile image animation.
- **Interactive Navigation:** Highlighted active links with underline animation.
- **Projects Showcase:** Displays featured works with live demo and GitHub links.
- **Downloadable CV:** Direct button to download my resume.
- **Auto-Updating Footer Year:** Dynamic JavaScript to show the current year.
